## Projects

- **[CyberShield](https://github.com/mohitrajjj/CyberShield)** — my MCA capstone, a multi-modal cyber-threat detection platform combining four ML models (XGBoost + Random Forest for phishing URLs, TF-IDF + XGBoost for job-fraud text, an image-forensics pipeline with Grad-CAM, and Isolation Forest for anomaly detection) through a weighted risk-fusion engine. 96.4% accuracy / 0.993 AUC-ROC on phishing-URL detection. Graded A+.
- **[HireSync](https://github.com/mohitrajjj/HireSync)** — a full-stack (MERN) recruitment platform with role-based dashboards for recruiters and candidates, JWT auth, an analytics dashboard, and CI/CD with automated tests.
- **[Toxicity Detection App](https://github.com/mohitrajjj/Toxicity-Detection)** — a Flask + PyTorch app using a fine-tuned BERT model to classify text across 6 toxicity categories, with batch analysis and a REST API. Built during my research internship at RVCE's Centre of Competence in Visual Computing.
- **[Canteeno](https://github.com/mohitrajjj/Canteeno)** — a canteen management web app with full order-to-wallet functionality: employees browse a menu, place orders, and have the total deducted from their wallet automatically, with order history for both employees and admins.
- **[SpendSense](https://github.com/mohitrajjj/SpendSense-flutter)** — a Flutter Progressive Web App for expense tracking and budgeting, installable and usable offline.
- **[FocusSense](https://github.com/mohitrajjj/FocusSense)** — real-time, privacy-first study-attention analytics using MediaPipe/OpenCV and an optional CNN/LSTM classifier, with a live Flask + SQLite dashboard. MCA minor project, built with Sameer Patel.
